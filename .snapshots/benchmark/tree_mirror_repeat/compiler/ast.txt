         '$apply$mirror' mutual cycle that the second SCC-merge pass fuses
         into one self-recursive function before TCO. This benchmark
         exercises that path under heavy memory pressure.

         Shape: a left-spine tree of depth 10_000 is mirrored 1000 times.
         Mirror is its own inverse, so 1000 (even) mirrors return the
         original tree; output is the value at the deepest left position
         (always '1' here, since 'buildLeft' fills every Node with 1).

         Per iter: 10_000 fresh Node cells (the new mirror tree) + ~20_000
         K cells (two per Node visited). Steady-state live set with proper
         refcount reclaim: two trees (~10_000 Node cells each) + at most

         reclaim: 1000 × 30_000 ≈ 30M cells stay live, ~1 GiB.
