         row-polymorphic in its error (`Either e Int32`).

         The combinator's result row `(e1 | e2)` then keeps two free variables after
         the operand is checked (`e1` bound to the operand's own free `e`, `e2` the
         continuation's), so a per-argument solve that only resolves a single free
         variable cannot pin `e2`. The inline continuation is then checked against an
         abstract `e2`; on the inner level its target row position is a bare variable,
         and an empty concrete-label set would bind the inner row variable to `Never`,
         rejecting the inline `Left EC` injection.

         The fix pins `e2` (and the unconstrained operand variable) to the full
         signature row once every operand has been checked — a sound upper bound,
         since `pureEither n` injects no error and per-label tags make the widening
         harmless. The inner `bindEither` then sees a concrete expected row and tags
         `EC`. The inline `Left EC` short-circuits the chain, so every backend
